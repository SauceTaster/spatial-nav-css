1 Mark up containers and focusables — plain HTML

Native buttons/links/inputs already participate. Add data-focusable to let plain divs (cards, tiles) join in.

<link rel="stylesheet" href="spatial-nav-css/spatial.css">

<nav data-spatial-container="remember">   <!-- restores focus on re-entry -->
  <button data-spatial-autofocus>Home</button>
  <button>Library</button>
  <button>Settings</button>
</nav>

<div class="grid" data-spatial-container="wrap remember">
  <div class="card spatial-pop" data-focusable>Card 1</div>
  …
</div>

2 Start the engine — three lines of JS

Keyboard arrows and every connected gamepad now move focus spatially. React to navigation through bubbling DOM events.

import { createSpatialNavigation } from 'spatial-nav-css'

const nav = createSpatialNavigation({ autofocus: true })
nav.start()

// hook in anywhere — events bubble like clicks:
document.addEventListener('spatial:focus',    e => { /* e.detail.source */ })
document.addEventListener('spatial:activate', e => { /* Enter / Ⓐ */ })
document.addEventListener('spatial:back',     e => { /* Esc / Ⓑ */ })

3 (Optional) Configure through CSS instead

Every knob is also a custom property, so it can live in your stylesheet, a media query, or a theme. Data attributes win when both are set.

.modal    { --spatial-container: contain; }        /* trap focus inside  */
.carousel { --spatial-container: wrap remember; }
.bottom-row button { --nav-down: none; }           /* block a direction   */
.search   { --nav-up: "#logo"; }                   /* explicit override   */

:root {  /* theme the shipped focus ring */
  --spatial-focus-ring-color: #1a9fff;
  --spatial-focus-ring-width: 3px;
}
