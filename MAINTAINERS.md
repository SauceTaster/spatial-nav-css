# Maintainers

## Current maintainership

The repository owner, [@SauceTaster](https://github.com/SauceTaster), is the
initial public maintainer contact. This file does not imply that every person or
organization with repository access has npm publishing access.

The project has not yet published dedicated private addresses for security or
Code of Conduct reports. Use the safe interim procedures in
[SECURITY.md](SECURITY.md) and [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md); do not
send conduct reports through the vulnerability channel.

## Responsibilities

Maintainers are expected to:

- review and merge contributions consistently with the project license and
  Code of Conduct;
- protect the compatibility, accessibility, security, and release quality of
  the public API;
- keep repository and npm access limited to people who need it and use strong
  account authentication;
- follow [RELEASE_CHECKLIST.md](RELEASE_CHECKLIST.md) for every release;
- disclose relevant conflicts of interest and recuse themselves when needed;
- keep security and conduct reports confidential; and
- record third-party provenance and retained notices in
  [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).

## Decisions and changes in maintainership

Routine changes are decided through pull-request review. Backward-incompatible
API changes, license changes, governance changes, and changes to the publishing
path require explicit maintainer approval and should remain open long enough for
community review unless resolving an embargoed vulnerability.

Maintainers may be added or removed through a pull request updating this file and
`CODEOWNERS`. Before granting release access, verify the person's GitHub and npm
accounts, require phishing-resistant two-factor authentication where supported,
and grant the minimum role needed. Removal from this file must be accompanied by
review of repository, npm, and any private reporting access.

Security response may happen privately before a coordinated disclosure. Any
lasting code, release, or policy change should be recorded publicly after the
embargo ends, without exposing reporter information.
