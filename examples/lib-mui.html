🎛 Material UI — portals, MUI's focus trap, roving tabindex

A server admin screen built from MUI Dialog, Menu, Select, Tabs, Switch, Checkbox and TextField, with data from MSW + TanStack Query. MUI portals its overlays to document.body and ships its own FocusTrap, so each wrapper documents exactly what spatial navigation needs from it. Drive with ←↑↓→, Enter, Escape.
