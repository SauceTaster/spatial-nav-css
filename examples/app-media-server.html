🖥 Media server admin — four zones, one data grid, one modal

A Jellyfin/Plex-style operations screen: libraries, an active-streams table built with TanStack Table where every cell is a spatial stop, user rows that mutate under the highlight, and storage pools. Data comes from MSW over fetch and is cached by TanStack Query. Stopping a stream goes through the library's own spatialConfirm() — the one place contain belongs. Drive with ←↑↓→, Enter; on a role <select>, ↑↓ change the value and → leaves the control.
